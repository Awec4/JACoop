How to join

  1. Install JACoop (the co-op build of AdvancedJK) and own a copy of Jedi Academy.
  2. Click Join now — your browser asks permission, then the game opens straight into the host's lobby. (First time only: run JACoop.exe once so it registers the link handler.)
  3. No install yet? Copy /connect <address> and paste it into the in-game console (~).
  4. Everyone needs the same mod version.
